Create a detailed implementation plan for: $ARGUMENTS

## Process

1. **Understand the codebase** — use Glob/Grep/Read to find relevant files, patterns, and existing conventions. Look for similar features to understand the established approach.

2. **Clarify scope** — identify what the task is NOT asking for and note any ambiguities.

3. **Design the plan** — produce a step-by-step implementation plan with:
   - Files to create or modify (exact paths)
   - What changes each file needs
   - Order of implementation (dependencies first)
   - Any new packages or tools required
   - Testing approach

4. **Surface trade-offs** — if there are multiple valid approaches, briefly note the main trade-off and recommend one.

5. **Use TodoWrite** to write the plan as a task list.

Do NOT write any code. The goal is alignment before implementation.
